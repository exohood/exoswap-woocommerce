
# Exoswap Cryptocurrency Payment Gateway for WooCommerce - Discontinued

> ⚠️ **PROJECT PERMANENTLY DISCONTINUED - CRYPTOCURRENCY PAYMENT GATEWAY**
>
> Exohood Labs. has permanently discontinued the Exoswap Cryptocurrency Payment Gateway for WooCommerce.
>
> **The payment gateway is no longer operational, maintained, or supported.**
>
> Exoswap does not currently provide cryptocurrency merchant payment processing, automated invoicing, WooCommerce payment integrations, or automatic conversion of customer payments into stablecoins through this discontinued service.

>

> **Project Status: Permanently Discontinued.**

## Project Overview

The Exoswap Cryptocurrency Payment Gateway for WooCommerce was originally developed as an integration concept for online businesses using WordPress and WooCommerce.

The project explored the possibility of allowing merchants to accept cryptocurrency payments through an automated checkout and invoice processing system.

Its original design included:

- Cryptocurrency payment processing for WooCommerce.
- Automated payment invoices.
- Blockchain transaction monitoring.
- Payment confirmation and order status updates.
- Cryptocurrency exchange rate calculations.
- Merchant wallet integrations.
- Automatic cryptocurrency conversion concepts.
- Support for multiple blockchain assets.
- Payment processing through the historical Exoswap API.

These features represent the original project's objectives and historical documentation.

**They are not currently available through this repository or the active Exoswap application.**

## Historical Payment Gateway Features

Earlier documentation described support for Bitcoin, Ethereum, EXO, and other digital assets.

It also proposed automatic payment confirmations, merchant settlement, and conversion of cryptocurrency payments into selected stablecoins.

The project previously referenced subscription plans, commission structures, and automated exchange rate calculations.

All such information is obsolete.

**Exohood Labs no longer provides these services or guarantees any previously advertised payment functionality, pricing, conversion rates, or settlement conditions.**

## WooCommerce Integration - Discontinued

The original plugin was designed to integrate with WordPress and WooCommerce.

Historical installation procedures included:

1. Installing the Exoswap WooCommerce plugin.
2. Activating the payment gateway.
3. Configuring API credentials.
4. Connecting merchant payment settings.
5. Enabling cryptocurrency payments at checkout.

**These instructions are no longer valid and must not be used for production payment processing.**

The former Exoswap payment gateway API is not maintained as an active merchant payment service.

Previously issued API credentials, integration instructions, and configuration references should not be considered valid or supported.

## API and Technical Support

Development and maintenance of the original payment gateway API have been discontinued.

The following services are no longer provided:

- Merchant API registration.
- Public or secret API token issuance for this gateway.
- WooCommerce payment processing.
- Automated cryptocurrency invoicing.
- Payment status synchronization.
- Automatic stablecoin settlement.
- Merchant payment dashboards.
- Gateway subscription services.
- Integration updates.
- Technical support for this plugin.

Previously published API documentation and implementation examples are retained exclusively for historical reference.
